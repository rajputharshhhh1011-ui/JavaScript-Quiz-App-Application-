# JavaScript Quiz App

**Project owner:** Md Adnan Ashraf  
**Technologies:** HTML5, CSS3 and Vanilla JavaScript

A responsive multiple-choice quiz application for practising basic web-development concepts.

## Features

- 10 multiple-choice questions
- One answer can be selected per question
- Immediate correct/incorrect feedback
- Score and progress indicator
- Final percentage and performance message
- Answer review at the end
- Best score saved in browser `localStorage`
- Light and dark themes
- Responsive layout for mobile and desktop
- No framework or installation required

## Run the project

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`, or open it in a browser.
4. Select an answer and use **Next Question** to continue.

No server, package manager or external library is required.

## Upload to GitHub (website method)

1. Sign in to GitHub.
2. Select **New repository**.
3. Enter the repository name `JavaScript-Quiz-App`.
4. Choose **Public** or **Private**.
5. Create the repository.
6. Select **Add file → Upload files**.
7. Extract this ZIP on your computer, then upload the five project files (not the ZIP itself).
8. Enter a commit message such as `Add JavaScript Quiz App`.
9. Select **Commit changes**.

## Publish with GitHub Pages

1. Open your repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Select **Save**.
6. Wait for GitHub Pages to publish, then open the URL shown in the Pages section.

## Upload with Git (optional)

Run these commands from inside the extracted project folder after creating an empty GitHub repository:

```bash
git init
git add .
git commit -m "Add JavaScript Quiz App"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/JavaScript-Quiz-App.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.
